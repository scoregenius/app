# Documents

Two documents written for readers evaluating the product rather than working on it.

| File | Covers |
|---|---|
| `interface_redesign.html` | What changed in the interface and why — the audit, the before and after, the build plan |
| `design_system.html` | The system itself — tokens, components, patterns, applied across the app |

Both are self-contained single files. Download and open in any browser, or use a raw-HTML viewer —
GitHub shows HTML as source rather than rendering it.

Every interface specimen in them is **rendered live from the design system's own token values**
rather than screenshotted, so they print at full fidelity at any zoom and follow the tokens if those
change. "Before" specimens are reconstructed from the shipping app using its exact colour and type
values, so the comparison is honest rather than flattering.

They draw on [`../design_system.md`](../design_system.md), which is the working reference.
