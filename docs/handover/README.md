# Documents

Two documents written for readers evaluating the product rather than working on it. Each is
published in both formats: the PDF opens in GitHub's own viewer, the HTML is the source it is
rendered from.

| Document | Covers |
|---|---|
| Interface redesign — [PDF](./ScoreGenius-Interface-Redesign.pdf) · [HTML](./interface_redesign.html) | What changed in the interface and why — the audit, the before and after, the build plan |
| Design system — [PDF](./ScoreGenius-Design-System.pdf) · [HTML](./design_system.html) | The system itself — tokens, components, patterns, applied across the app |

The HTML files are self-contained — one file each, no assets to fetch. Download and open one in any
browser, or use a raw-HTML viewer; GitHub shows HTML as source rather than rendering it. The PDFs
carry the same text, set on Letter pages: fifteen for the redesign, eighteen for the design system.

Every interface specimen in them is **rendered live from the design system's own token values**
rather than screenshotted, so they print at full fidelity at any zoom and follow the tokens if those
change. "Before" specimens are reconstructed from the shipping app using its exact colour and type
values, so the comparison is honest rather than flattering.

They draw on [`../design_system.md`](../design_system.md), which is the working reference.
